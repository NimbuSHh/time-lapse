# Time-lapse

面向 Adobe Camera Raw 照片序列的本地延时摄影工作台，提供曝光台阶修正、短时去闪烁、预览视频与全尺寸 JPG/XMP 导出。自动流程使用本机 Photoshop / Camera Raw 显影，另保留手动分析与校准工具。

所有计算在本机进行，RAW 始终只读。分析和仅导出不会修改输入 XMP；“自动备份并写回”会先备份，再替换 RAW 同目录的 XMP。自动流程在独立工作副本上处理，生成完整预览后等待用户观看确认。

当前为 **0.1.0 早期版本**。已加入亮度目标与曝光换算分离、显影来源核对和冻结目标反馈；自动化测试使用合成素材，不能替代真实 Adobe 显影与成片检查。不同素材和机器仍需验证，不宣称等效替代 LRTimelapse。

## 启动

需要 **macOS、Python 3.12+**。一键自动处理还需要本机已安装 **Adobe Photoshop / Camera Raw、ffmpeg 和 ffprobe**；Adobe 软件需自行安装和许可，不包含在本仓库中。已有 Homebrew 时，可用 `brew install ffmpeg` 安装视频工具。Node.js 仅用于开发检查。

首次安装：

```sh
git clone https://github.com/NimbuSHh/time-lapse.git
cd time-lapse
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./run.command
```

以后双击 **run.command**，或在项目目录执行 `./run.command` 即可。下载 ZIP 的用户解压后可跳过克隆步骤；若启动文件没有执行权限，先执行 `chmod +x run.command`。自动显影首次启动时，按 macOS 提示允许启动工作台的应用控制 Photoshop。

程序自动打开浏览器并使用空闲本机端口。终端关闭或按 Ctrl+C 后服务停止。启动链接含本机会话密钥，不要发给别人。照片不会上传；输出包的清单含本地路径和文件名，属于你的本地工作资料。

更新程序后需重新启动工作台，并使用新打开的页面。每个服务固定使用启动时的页面文件，避免新页面调用旧后台；联合调色入口会检查后台是否支持联合调色。旧后台缺少功能时提示重新启动，不应要求重做分析。联合调色入口可直接使用小图和已有联合包，不依赖主流程的临时分析记录。

## 一键自动处理（默认）

选择新的 RAW 素材文件夹，点击 **开始自动调色**，直接进入整段亮度修正流程，不需要先完成旧自动任务或手工准备校准图。沿用已保存的同名 XMP；没有 XMP 时使用本机 Camera Raw 默认设置。

自动显影依赖 **macOS、本机 Photoshop / Camera Raw、ffmpeg 和 ffprobe**，并需要系统允许程序控制 Photoshop。先保存并关闭 Camera Raw 窗口；处理期间由程序使用 Photoshop，不要同时编辑工作副本或在 Photoshop 中处理其他照片。

流程分为两段：

1. **生成完整预览。** 自动准备 RAW 工作副本，选择与冻结测量区域，估计持续曝光台阶，计算并实际显影修正，完成数值检查，生成覆盖全序列的低分辨率视频。默认 25 fps。视频生成后固定停止，等待观看确认。
2. **确认后导出。** 在页面载入并完整观看视频，检查明暗起伏、闪烁、色彩和自然光变化。数值检查通过且勾选“我已完整观看这版视频”后，点击 **确认并导出全尺寸 JPG 与 XMP**。导出绑定这次视频、帧清单、冻结目标和有效配方；预览版本变化必须重新确认。全尺寸 JPG 由 Adobe 使用对应配方重新显影，完成后显示独立交付目录。

默认按素材选择测量区域，不预设天空、海面或建筑位置。若自动选区无法获得可靠区域，页面会保留进度并说明原因；可展开 **高级：调整测量区域**，指定亮部、参考区域和两个检查区域的矩形范围后重新生成。坐标按画面宽高的百分比填写，从左上角起算；区域只用于测量，不裁切照片。检查区域用于独立观察局部变化，选区不能替代对画面内容的判断。

全部新结果、中间显影、独立 RAW 副本及任务记录保存在 **所选素材目录 / Time-lapse工作/**；禁止写入程序项目目录。也可用 `./run.command --workdir '/指定工作目录'` 明确工作位置。嵌套在已有 `Time-lapse工作` 内的素材复用该工作目录。旧版项目 `outputs` 只读兼容，不继续写入。

自动流程不覆盖原 RAW/XMP。可点击 **停止并保留进度**；刷新页面会重新连接任务，重启后可继续已有任务。恢复前核对源文件与已保存结果，符合当前任务的显影才会复用。视频确认不会因数值通过、刷新或恢复而自动发生。导出失败或停止时保留预览和进度，可重新确认后重试。进度按当前阶段的实际帧数显示，不代表剩余耗时。

未通过数值检查的候选仍可观看，但不能直接正式导出全尺寸。自动测量不识别创作意图，镜头移动、复杂局部变化、无法可靠分离的自然光变化与相机调参仍需人工判断。完整预览不能证明全尺寸细节完全一致，交付后仍应检查细节。

当前方法已在原有一组素材上获得用户认可；本次通用化不等于跨素材和跨机器实测完成。下一步验收是用独立新素材从头运行，确认无需改代码即可完成预览、明确确认和全尺寸交付，或能对不适用情况说明原因并保留进度。

## 手动调整与高级工具

展开首页的 **手动调整与高级工具** 可使用以下原有流程：

1. **选素材。** 在 ACR 保存同名 XMP，用当前设置导出同名 sRGB JPEG，保持裁切与尺寸一致。选择 RAW/XMP 和小图文件夹；同目录时勾选“JPG 也在这个文件夹”，再点击“分析序列”。不需要额外勾选格式或顺序声明，程序直接检查文件。默认整图测光，需要时展开“测光与拍摄选项”框选稳定区域。目录仅读取顶层，每个 RAW 须对应唯一的同名 XMP 和 JPEG。
2. **调整。** 调节平滑强度，勾选确认由相机调参造成的曝光台阶。默认保留全部候选；连续调参按组选择。平滑窗口、拍摄间隔接缝和首尾偏移放在“更多调整”中。默认保留原片首尾亮度；参数改变后点击“更新预览”。
3. **预览。** 查看原始亮度与绿色目标曲线，拖动帧滑块或连续播放检查小图。绿色曲线是待实现的亮度目标，实际效果须在 ACR 重新显影查看。测量诊断、计算说明和逐帧曝光值默认收起，有需要再展开。
4. **导出。** 预览有效后，在导出区选择“导出到原目录的新建子目录”（默认）、“备份 + 导出到原目录”或“自行指定目录”。新建子目录模式生成独立的 `timelapse-…/package/`，含 `corrected/`、`originals/`、清单与说明。自选目录模式直接把修正 XMP 保存到所选目录，不创建子目录；遇到同名文件则整批停止，不覆盖已有文件。主流程修正包不允许保存到项目目录下。备份模式需先关闭 ACR 并勾选确认，程序完整备份到原目录的 `Time-lapse-XMP备份/` 后才替换同名 XMP，可用已有恢复入口还原。修正值已叠加原曝光，RAW 始终只读。独立包需将 corrected 应用到 RAW 工作副本，再用 ACR 重新显影检查效果。

素材被修改、预览过期、缺少曝光换算依据或曝光超过 ±2 EV 本轮增量 / ±5 EV 最终值时，程序会说明具体原因并停止导出。亮度变化与 XMP 曝光变化不能直接等同；相机参数估计只是换算先验，真实显影仍需复核。

缺少换算依据时，在 **导出 → 曝光校准（保留当前目标）** 完成当前流程：

1. 点击“生成两组曝光校准 XMP”，获得 `baseline/` 和 `probe-exposure/` 两套全序列 XMP。后者逐帧只改变曝光 0.2 EV，方向按目标选择，到达曝光边界时反向；不调整高光、白色色阶或其他设置。
2. 在独立 RAW 工作副本中分别应用这两套 XMP，用 ACR 导出到两个小图目录，保持原尺寸、裁切、同名 sRGB JPEG，保留全部元数据。
3. 导入两组小图完成校准。程序核对逐帧身份、显影设置和固定测光像素，要求基准重显影与原预览的亮度偏差不超过 0.04 EV，再将实测曝光响应接回当前目标。通过后即可用原来的“导出修正包”，仍须对候选实际显影复核。

该校准保留当前绿色曲线、台阶选择与测光区域，不必进入三参数联合调色。同一分析内调整目标会保留待导入的校准包，并复用已完成的曝光响应；导入时核对当前目标版本及原素材、测光规则。刷新或重启后也恢复校准计划。重新分析、更换素材或测光区域后需重新校准。缺帧、配方不符、基准无法复现或响应不足时不会放行导出；原素材始终只读。

导出下方的折叠入口保留后续操作：

- **写回原目录（先备份）**：确认关闭 ACR 后，可自动备份并替换同名 XMP。RAW 不变，写回后本轮目标冻结。
- **更多操作 → ACR 重新显影复核**：分析并更新预览后，选择同名、同尺寸的 ACR 小图即可对照当前亮度目标检查误差，无需先导出修正包。缺少曝光校准或曝光超限只限制 XMP 导出，不阻止亮度复核。按钮旁会说明缺少分析、预览失效、未选目录或任务进行中等不可用原因；测量失败也在此显示具体原因。
- **更多操作 → 保留冻结目标的残差修正**：可直接使用当前已保存的分析目标，来源包留空即可，无需先导出；也可选择原备份、修正包或上一轮反馈包。选首次原始小图、实际用于最新显影的 XMP 和最新小图，来源、设置和身份核对后生成下一轮独立候选。目标和初始曝光基线跨轮不变；个别帧缺乏响应依据时保留其 XMP，其他有依据的帧可继续。页面列出逐帧原因和处理建议，“用此包开始下一轮”会同步来源和 XMP 目录并清空旧显影目录。
- **更多操作 → 联合调色与校准 / 恢复原 XMP**：按需使用，操作规则见下文。

在“恢复原 XMP”中读取当前 RAW 目录的备份，选择最新备份、确认已关闭 ACR，再点击恢复。无需重新分析，重启后也可使用；多次写回按从新到旧的顺序撤销，备份始终保留。发现新编辑或备份损坏时会拒绝自动恢复。如果修改恰好发生在交换瞬间，操作会停止，并给出 retained 中保留下来的冲突版本路径；应先人工核对，不能直接继续覆盖。

写回和恢复逐文件原子交换，将实际换出的文件保留在备份中，不直接删除旧文件。整批不是一次原子事务；中断后可能部分文件已替换，此时从备份恢复即可继续，未完成的操作会阻止新写回。完整备份落盘后才开始覆盖。不支持安全交换的文件系统会明确拒绝写回，绝不降级为直接覆盖。程序无法锁住外部 ACR，因此操作期间仍须关闭该序列。已用故障注入和真实子进程退出测试验证，不等于验证了所有 NAS、磁盘故障或物理断电场景。同一分析快照不能重复写回；多次独立分析采用持久递增版本号确定恢复顺序，不依赖系统时钟。

每次成功计算或曝光校准后，当前分析目标、测光参考和展示数据自动原子保存到 `工作目录/Time-lapse工作/verification-target.json`，不生成或写回 XMP。刷新页面会恢复最近一次成功保存的目标；重启服务后也能恢复曲线、逐帧预览及复核。新记录同时保存原 XMP、来源指纹及曝光校准计划，重启后可继续调整和校准；导出或写回前仍检查源文件未变化。写回开始前保存快照已使用状态，防止中断重启后重复写回。旧版缺少来源记录的目标仍可查看、复核和做有完整来源核对的残差修正；继续调整需重新分析。参数修改后尚未更新预览时，当前页面暂停复核；刷新会恢复上次保存的参数和目标。新分析结果会替换此恢复记录，已导出的历史包不受影响。

已有导出包仍可独立复核，使用其 `manifest.json`，或自动备份目录中的 `verification.json`：

```sh
.venv/bin/python -m timelapse.server \
  --verify-manifest '/绝对路径/package/manifest.json' \
  --previews '/绝对路径/重显影小图'
```

## 为什么这样设计

调参台阶和残余闪烁是不同的问题。单凭 JPEG 无法唯一分离相机曝光与自然光变化，所以相机参数只提供候选位置，最终阶跃取自图像观测并由你确认。sRGB 线性化后的亮度增量也不等同于 ACR 非线性显影结果，因此重显影验证是必要环节。

有跳变估计的候选均可勾选、预览和撤销；方向、幅度、噪声、趋势及响应一致性检查只决定判断提示，不决定选择权限。空间检查参考固定测量像素的权重，以至少 75% 支持同向变化为建议标准；连续调参还逐网格检查各短平台是否符合该区域自身的响应。明暗区域经显影后的跳变幅度可以不同，因此网格幅度差异仅作诊断。未通过检查的候选展开显示“需人工判断”，手动选中后仍不作为自动曝光换算的依据；预览结果记录这些候选及疑点。

连续调参窗口内已有 XMP 曝光变化时，仍从当前图像测量各段剩余跳变，可整组勾选，但标为需人工判断且不作为自动曝光换算依据；不会把已有 XMP 或相机 EV 再叠加为修正量。组内净 XMP 变化为零也不代表没有编辑，各段编辑断点仍分别保护。

当前方法因窗口不足、时间缺口、连续调参跨度过长、组内独立 XMP 编辑断点或拍摄参数缺失、不稳定而未生成估计的位置，收纳在“未生成估计”说明区，可点击查看对应帧，不展示灰色复选框。勾选候选与导出 XMP 是不同阶段：缺少亮度到曝光的换算依据时仍可查看亮度目标，但需要校准后才能导出；曝光范围和源文件一致性检查仍适用。

当前支持现代 ACR `Exposure2012` 的 UTF-8 XMP，支持属性或简单子节点；除曝光数字外的字节原样保留。额外调色字段、蒙版等不会被重新序列化。ROI 测量并不理解云层、镜头运动、局部蒙版或 AI 自动调整；有这类变化时应人工判断或分段处理。

自然文件名顺序是首版默认顺序；文件编号回卷、多相机或不规则拍摄间隔需要先分组，不能依赖文件排序自动恢复真实时间线。拍摄时间缺失时会提示无法检测时间缺口。

“更多调整”默认开启「平滑拍摄间隔接缝」：对调参停顿等仅有时间缺口的位置，在所选平滑窗口内连续衔接目标亮度，保留窗口外及首尾目标。它独立于去闪烁的平滑强度，可关闭对照；不会跨越未确认的曝光台阶或已有曝光编辑。窗口两侧样本不足时保留原状。该处理是输出连续性的选择，不补拍摄帧，也不推断停顿期间的真实光线；结果记录实际衔接的位置，已保存的旧目标不会被改写。

## 测量诊断与冻结兼容

新测量使用 `roi-fixed-support-v3`，只保留实际采样数量检查；覆盖和保留率用于诊断：

- **固定有效覆盖**：显示全程固定有效像素占 ROI 采样点的比例，不设占比门槛，避免相同可用像素因扩大选区而被拒绝。
- **实际采样数量**：至少 1024 个不同的 JPEG 像素。长边按不超过 512 个位置抽样，步长由整张图决定；缩小 ROI 不会放大像素或增加独立证据。它不是 RAW 像素数量，也不证明统计独立性。
- **时间诊断**：显示固定交集占“单帧最多有效像素”的比例。这个比例描述候选像素的损失，不证明剩余固定像素不可靠，因此不再使用 80% 阻断门槛。只要全程固定支持通过数量检查，较低保留率本身不会阻止分析。没有任何可测像素时显示“无法评估”，不冒充局部运动检测。各格相对全局变化的差异另作检查提示（相邻变化超过 0.2 EV 或相对变化跨度超过 0.5 EV），不据此排除网格。非线性显影下，静态明暗区域对同一次曝光也会有不同响应。

采样数量下限是工程保护值，不是通用摄影标准。高光（任一 sRGB 通道 ≥98%）和深黑（所有通道 ≤2%）标准不变；它们只剔除对应像素，而不是整格。亮度差异可能来自运动物体、局部自然光、显影或裁切变化，不能据此认定原因；像素保留率也不能证明景物未移动。小 ROI 通过也不能代表全画面。

分析成功或失败后均可展开测量诊断，查看采样数量、覆盖与保留率、ROI 内网格及相关帧。诊断不会自动展开。点击格子查看含剔除像素的帧或亮度变化差异帧，也可按帧在 JPEG 上标出位置。橙色表示有问题像素或局部变化，不代表整格都已排除。分析失败时停止计算并撤销旧活动快照的导出入口。

分析只读取、解码每张 JPEG 一次，同时筛选固定像素并暂存抽样亮度。读取结束后复用抽样数据汇总曲线，不再次打开原小图；进度按实际帧数显示一次。缓存只含抽样亮度，超过 64 MiB 后转入本机临时文件，成功或失败后均自动清理。

新包保存测量版本、确切像素支持和权重。后续复核及残差反馈沿用它们，不按新图重新挑区域。v2 包沿用其已冻结的支持与原验证规则；没有测量版本的旧包继续执行原来的 ROI 缩图和共同网格算法；旧目标、旧包及素材不会被迁移或改写。新规则只用于明确发起的新分析。

v3 冻结参考在复核、曝光校准或残差反馈时出现少量高光/暗部失效，不再仅凭一个失效像素拒绝整帧。程序保持全部原像素及权重，用暗部线性亮度区间 `[0, 0.02/12.92]`、高光区间 `[0, 1]` 分别计算网格中位数及最终加权中位数的上下界；上下界与原算法实测值**完全相同**时，才能标为严格可比。没有百分比豁免或误差容忍，也不替换参考像素或重算目标；无法证明最终值不受影响时，严格调用仍拒绝将其作为已校验残差。这个检查只约束 JPEG 测光统计，不代表恢复了 RAW 高光或暗部细节。

页面复核是诊断查看：少量或大量帧未通过严格可比性检查时，仍返回全部 JPEG 实测曲线与统计，明确标注通过/待确认帧数、逐帧高光/暗部数量、保守测光与误差区间，并提供帧定位。全序列 RMSE 区间按逐帧误差区间计算；旧测量规则无法界定时明确显示未知，不当作零误差。未通过的帧用空心圆标记，结果不宣称整批可比，可把已完成测量的小图沿用为后续分析来源，但不代表校验通过。固定像素、权重与目标均不改变。默认命令行严格复核保留严格可比要求。曝光校准和残差反馈使用完整测光区间：整个响应区间必须满足有效响应要求，按保守端点计算步长；目标落在不确定区间时不猜测方向，缺少有效区间时保留该帧。身份、文件指纹或显影设置冲突仍只生成诊断。

## 独立反馈包与跨轮验证

反馈包中的 `review.html` 展示原始、冻结目标、最新实际测量和明确标注的下一轮预测；`curves.csv` 包含逐帧亮度、当前曝光、候选绝对曝光和本轮增量。`source-audit.json` 保存来源证据，`current-verification.json` 保存此次真实残差。

`corrected/` 是候选 XMP，`originals/` 是本轮输入，`baseline/` 是首次修正前的不可变基线。`sample-corrected/` 与 `sample-plan.json` 包含首尾、亮度极值及各断点完整估计窗口。先把这些 RAW 复制到独立工作目录，配对样本 XMP，在 ACR 重显影；再检查全序列，不能用拟合误差或预测曲线代替真实验收。

也可从终端生成包（支持首次写回备份、导出包或上一轮反馈包）：

```sh
.venv/bin/python -m timelapse.feedback \
  --source '/绝对路径/备份或package目录' \
  --original-previews '/绝对路径/首次原始小图' \
  --current-xmps '/绝对路径/当前工作副本' \
  --previews '/绝对路径/本次重显影小图' \
  --output '/素材工作目录/Time-lapse工作'
```

后续轮次将 `--source` 指向上一轮输出的 `package`，仍使用首次原始小图。每轮重新核对实际 XMP 和新 JPEG，保持最初目标、基线和每个断点定义。JPEG 缺少嵌入显影设置时不能自动完成来源核对。JPEG 中曝光通常记录到两位小数，因此报告舍入差并限制在 0.0051 EV；元数据核对不能独立鉴证像素的生成过程。

## 曝光、高光、白色色阶联合反馈

高级流程在 **手动调整与高级工具 → 更多操作 → 手动联合校准** 使用三步引导，默认自动选区与计算，每次只显示当前步骤：

1. **准备**：沿用第 01 步或最近复核的小图，点击“开始自动准备”。无需先做主流程曝光导出。手动选区、平滑窗口和已有包恢复放在折叠项中。
2. **导入小图**：页面列出四套 XMP 与各自的 JPG 保存位置，可一键复制。用同一套 RAW 工作副本依次读取四套 XMP，在 ACR 导出四组全序列 JPG。新包已建好 `jpg/baseline`、`jpg/probe-exposure`、`jpg/probe-highlights`、`jpg/probe-whites`，返回页面点击“已导出四组小图，自动计算”即可。若保存在别处，可选一次总文件夹或分别指定四个目录。默认直接处理全序列；小样仅供高级试验。
3. **检查效果**：完整修正生成后，自动显示 `corrected` 目录。用其中的 XMP 再显影一组小图，选入后点击“检查效果”。有残差可一键“继续改善剩余跳变”；数值通过后仍需播放确认，再在 ACR 导出最终成片。

仅在该高级手动流程中，ACR 显影由用户在 Adobe 中完成；首页一键流程会自动完成显影。软件负责选区、路径衔接、校准检查与修正计算，不改动源 RAW/XMP。刷新页面保留步骤、目录与最近结果；修改准备条件会清除旧候选，重新准备成功后清除上一轮小图路径。切换第 01 步序列会清除旧来源和联合包。仅填写复核目录或复核失败不会提升为下一轮来源。成功测量后的来源会自动沿用（有残差不等于数值通过）。校准不完整时直接显示待处理帧数和处理方法，不开放第 3 步。

“保留冻结目标的残差修正”仍只修改曝光，两个流程的来源包不能混用。

首轮从最新 JPEG 的内嵌设置重建独立校准 XMP，因此可以分析“ACR 中已调整高光，但尚未保存到原 XMP”的导出结果。`baseline/` 是显影设置的重建件，**不是原目录 XMP 的备份**。原 RAW、XMP、JPEG 均不写回。JPEG 中的曝光通常只保留两位小数，因此必须先用基准 XMP 重显影，确认六项测量与原小图的差异均不超过 0.04 亮度 EV。

默认自动分析完整序列，在 32×24 网格中依据持续可测程度、相对亮度、触顶比例及去除全局亮度变化后的局部稳定性，选择最多 48 个中间调网格和 32 个高光网格。它不识别海面、建筑、云或太阳；点击“查看自动区域”可换帧检查。选定网格在全序列和后续反馈中固定，并保存指纹，不会每帧追随最亮物体。缺少可靠区域时提示手动选择，不会退回整图猜测。旧手动选区包保持兼容；已有目标不会因新增自动选择而改变。

也可切换“手动框选”：中间调选有细节的大片海面或受光建筑，避开黑色剪影、灯光、强反射和运动物体；高光选有层次的晨曦亮带或亮云，避开纯白太阳和大片暗部。通过帧滑块检查前、中、后段，确认整个序列都可测。

测量包括中间调有效像素、高光区域、该区域最亮 5% 像素及全图三个颜色通道的亮端；另记录各通道接近顶格的像素比例。配对显影固定使用首次基准图的像素集合，避免每次调参后更换测量对象。像素抽样用于预览诊断，不能证明 RAW 剪切或恢复能力。

多区域目标在首轮冻结，局部线性平滑默认使用 31 帧，保留慢变化并在时间缺口、其他调色设置变化处分段。相机调参位置单独列出供检查。它不识别云层、不推断真实光照，也不自动等同于最理想的艺术目标。

生成的包包含 `baseline/`、`probe-exposure/`、`probe-highlights/`、`probe-whites/` 四套全序列 XMP，以及对应的 `sample-*` 小样。校准用 XMP **不是最终修正**。在独立 RAW 工作副本上按组应用，分别导出四个同名 sRGB 小图目录。三组扰动分别只改变曝光 0.2 EV、高光 10 或白色色阶 10；到达下限时改向上扰动，实际数值逐帧记录。

校准入口检查帧身份、完整显影设置、文件哈希、尺寸和基准复现，再逐帧计算三个参数的独立响应。求解同时考虑六项测量、参数上下限、单轮步长、累计曝光上限和颜色通道上限。参数本身可以在快门切换处跳变，不对参数数字强行平滑。单轮曝光不超过 0.2 EV、高光与白色色阶不超过 10；累计曝光相对本联合流程首次基线不超过 2 EV。

只提供小样时，仅导出有可靠校准的 `sample-corrected/`；缺失帧不插值猜测。响应无法区分、基准无法复现或无可行改善时会报告具体状态。只有全部帧通过才生成 `corrected/`，而这仍是**尚未经 ACR 复核的候选**。

复核入口测量实际重显影结果，报告分区域误差、剩余相邻跳变及通道剪切变化。数值门槛为前三项最大误差 0.08 EV、相邻残差 0.06 EV、各通道剪切比例增加不超过 0.1 个百分点，且通道亮端不超目标 0.02 EV；播放与色相检查仍由使用者完成。有残差时，将完整修正包作为下一轮来源重新分析新显影，保持最初目标、像素参考与曝光基线，重新校准本轮响应。

```sh
.venv/bin/python -m timelapse.joint_feedback prepare \
  --previews '/最新显影小图' --region-mode auto --output '/素材工作目录/Time-lapse工作'

.venv/bin/python -m timelapse.joint_feedback calibrate \
  --source '/联合校准包' --baseline-previews '/基准重显影' \
  --exposure-previews '/曝光校准' --highlights-previews '/高光校准' \
  --whites-previews '/白色色阶校准' --output '/素材工作目录/Time-lapse工作'

.venv/bin/python -m timelapse.joint_feedback verify \
  --source '/完整联合修正包' --previews '/候选重显影' --output '/素材工作目录/Time-lapse工作'
```

手动区域可使用 `--region-mode manual --mid-roi .05 .51 .42 .80 --high-roi .03 .37 .76 .47`；这只是本次海景的例子，其他构图应重新框选。校准计算的单元与端到端测试使用独立合成显影模型，不能替代 Adobe 实测。

## 整段亮度轨迹与视频确认

首页默认流程与 `/trajectory` 使用同一当前任务；后者用于查看、继续、停止以及确认已有视频后导出。新素材从首页选择即可开始。流程先用图像和相机参数估计持续曝光台阶，按组处理密集调参，再将去台阶后的自然变化映射到首尾亮度范围。目标与测量区域按任务冻结，原手动功能及旧结果保留。首尾映射是成片动态范围选择，不声称恢复物理场景光照。

曝光主要负责整体亮度；高光、白色色阶和主曲线的候选根据实际显影响应判断，保持原有调色设置及剪切保护。多个区域分别用于目标匹配与交叉检查，不使用固定海景位置。逐帧数值条件、事件与多尺度变化分别记录；配方、区域和目标的身份与完整视频一并保存。

**生成视频后固定停在 `awaiting-user-review`。** 数值通过、重新启动或恢复任务都不会触发全尺寸导出。页面载入视频时核对内容与保存的版本，用户完整播放并明确勾选后，才能请求导出这版配方。后端再次核对确认的版本与当前结果；不匹配或数值未通过时拒绝导出。独立交付保留对应 XMP、全尺寸 JPG 及来源记录，不覆盖原素材。

已有旧版完整预览也可确认导出：保留原视频、目标及配方，重新核对来源、逐帧显影记录和实测条件，导出进度另存。校验信息不完整时页面说明禁用原因。同一素材的新准备中途停止后，上次完整视频仍可载入确认，新准备进度保留。

旧联合流程的“目标误差通过”仅表示接近其冻结目标。旧目标可能将相机台阶平滑成缓慢明暗变化，不能据此认定成片效果合格。
